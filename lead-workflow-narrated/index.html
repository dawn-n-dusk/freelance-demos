This workflow captures new enquiries and stops reminders when a customer replies.

It checks the enquiry, saves the contact, and notifies the right person.

If the same event arrives twice, its work happens once, avoiding duplicate records and messages.

A customer reply is preserved, even after another form submission, so the next reminder is blocked.

For a temporary rate limit, the demo calculates a wait before a limited retry.

Expired access stops the workflow for review. It doesn't keep retrying the same failure.

If a write may have succeeded, check the remote record before repeating it.
