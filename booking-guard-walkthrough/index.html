Here is a customer asking for an appointment. The workflow checks the request and calendar before it confirms anything.

When the time is available, the demo creates one booking and returns its reference, so the customer knows it is confirmed.

If the same request arrives again, it returns the existing reference instead of booking twice. The booking count stays at one.

If the calendar is unavailable, it clearly says the appointment is not confirmed and leaves the request for follow-up.
